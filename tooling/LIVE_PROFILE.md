## New fixture

    /opt/homebrew/bin/node --preserve-symlinks tooling/check_live_profile.mjs --run-model --compact

This creates a fresh private Caches home and project, sends inert random context data until a completed root compaction appears (at most five fill turns), and then asks the continuity question. It does not alter model loading, persistent model settings, original owners, or user histories.

Every run gets a fresh .artifacts/live-profile/run-* directory. All failures remain visible. Cleanup and source verification run in finally. Unexpected tools, child items, approvals, missing usage, runtime mismatch or changed source fail qualification. Capture bounds constrain the acknowledgment fixture report; the model's uncapped output policy is not changed.

The 26 cases exercise exact runtime/effective-window semantics, wrong or missing replies, tool/child rejection, root-only completed compaction, retained failure identity, source-pin mismatch, shutdown failures, private/canonical path checks, symlinks, writable receipts, and unchanged-evidence verification. They use generated Caches fixtures and do not qualify native model behavior.
